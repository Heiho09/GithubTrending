# 상세 주간 요약 작성 기준

주간 Trending 스냅샷의 상위 5개에 대해 다음 내용을 한국어로 작성합니다.

1. **목적:** 어떤 문제를 해결하는 저장소인지 한두 문장으로 설명합니다.
2. **주요 기능:** README에 명시된 핵심 기능을 구체적으로 소개합니다.
3. **구성 방식:** 확인한 디렉터리, 언어, 구성요소와 각각의 역할을 설명합니다.
4. **활용 대상:** 어떤 작업에 쓸 수 있는지 설명하되 추정은 구분합니다.
5. **근거:** 실제 읽은 README와 소스 경로의 링크를 붙입니다.

Trending의 별 수만으로 인기의 원인을 추측하지 않습니다. 직접 실행하지 않은
기능을 검증했다고 표현하지 않습니다. 스냅샷 수집일과 README 조사일을 구분합니다.
접근에 실패하면 GitHub 페이지와 raw README 등 읽기 전용 경로를 확인하고,
끝내 확인하지 못한 내용은 추측으로 채우지 않습니다.

이번 상세 초안은 Codex의 **gpt-6.1-terra / medium** 분석 에이전트로 작성합니다.
이 선택은 Codex 실행 모델 설정이며, 외부 API 모델 ID나 GitHub Actions용 API
인증 설정을 의미하지 않습니다. API 모델 목록이나 인증을 확인하지 않은 상태에서
해당 이름을 API 요청에 넣지 않습니다.

출력은 `reports/YYYY-Www-analysis-draft.md`에 저장합니다. h1 제목과 h2 저장소별
제목, 굵은 라벨이 있는 문단으로 구성하고 다음 명령으로 PDF를 만듭니다.

```bash
.venv/bin/python export_report.py reports/YYYY-Www-analysis-draft.md
```

현재 예약 워크플로는 원문 설명 기반 Markdown/PDF 수집만 자동화합니다.
이 상세 분석 단계의 무인 API 실행은 아직 연결하지 않았습니다.
